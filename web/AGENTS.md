# Workbench UI

Read [the product design guidelines](../docs/design/DESIGN-GUIDELINES.md) before changing this UI. The user's explicit reference is the ElevenLabs application: white and neutral surfaces, compact navigation, black primary actions, readable typography and progressive settings.

Work with the existing React, TypeScript and CSS stack. Preserve API contracts, exact protocol approval, budget enforcement, recovery semantics and explicit publication. Display real measurements and uncertainty; never add mock runtime data to make a screen look complete.

Use the applicable `ui-design-frontend` and `react-best-practices` skills. The repository design guidelines and explicit user direction override generic style recommendations in those skills. Test changed behavior, run the production build, and visually inspect desktop and narrow layouts before claiming completion.
